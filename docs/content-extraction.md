Runtime content lives in `content/manual_amarelo_laranja.json`.

## Review Rule

Do not add new grading requirements directly in code. Add them to the curated content file only after checking the manual or receiving reviewed coach/parent input.

## Child-Friendly Adaptation

The app may simplify explanations for a 5-year-old, but every item must retain:

- original Japanese term
- Portuguese meaning or category
- manual-backed text
- accepted answers
- original visual cue when the item is a technique or movement concept

Visual cues should be short memory aids for a child. They must not imply detailed technical instruction beyond the manual and teacher guidance.
